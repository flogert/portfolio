# Security Policy

## Supported Versions

Security fixes are provided for the current production code on the `main` branch.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |
| Older branches or forks | No |

## Reporting a Vulnerability

If you find a security issue in this site or its source code, report it privately by email:

- `flogertbardhi@gmail.com`

Please do not open a public GitHub issue for security reports.

Include the following when possible:

- A clear description of the issue
- Steps to reproduce it
- A proof of concept or example request
- The affected page, component, or dependency
- Any suggested remediation

## Response Expectations

- Initial acknowledgement target: within 5 business days
- Status updates: provided as fixes are evaluated
- Remediation timing: depends on severity and reproducibility

## Scope

This policy covers vulnerabilities in:

- The deployed portfolio site
- Source code in this repository
- Production dependencies used by the site

This policy does not cover:

- Spam or automated scanning without a demonstrated impact
- Social engineering, phishing, or physical access attacks
- Issues that require compromised third-party accounts or infrastructure outside this repository
- Denial-of-service testing or any activity that degrades site availability

## Disclosure Guidelines

Please:

- Give reasonable time to investigate and remediate before public disclosure
- Avoid accessing, modifying, or deleting data that does not belong to you
- Avoid actions that could harm the availability or integrity of the site

There is currently no bug bounty program for this repository.
